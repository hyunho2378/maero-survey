영상 재생을 강제로 요구하지 않는다.

영상 문항에는 보지 못했다는 응답을 제공한다.

## 완료 화면

마에로 기본 모습, 물의 모습, 불의 모습을 표시한다.

처음과 지금 점수를 표시한다.

점수 차이는 응답 변화로만 설명한다.

공식 사이트는 새 탭으로 연다.

로컬 저장과 서버 저장의 완료 문구를 구분한다.

## 관리자 화면

?admin=1에서 연다.

로컬 모드는 현재 브라우저의 응답만 보여 준다.

서버 모드는 관리자 토큰을 입력해야 데이터를 반환한다.

관리자 토큰은 URL이나 Vite 환경 변수에 넣지 않는다.

응답 표, 처음 평균, 지금 평균, 전체 응답 CSV를 제공한다.

CSV에는 답변과 자동 기록을 함께 포함한다.

## 데이터 흐름

화면 노출과 상호작용은 제출 전까지 메모리에만 보관한다.

제출 시점에 응답과 기록을 하나의 ID로 묶는다.

VITE_ENDPOINT가 없으면 localStorage에 저장한다.

VITE_ENDPOINT가 있으면 Apps Script로 JSON 문자열을 POST한다.

서버 저장 실패 시 로컬 저장으로 몰래 전환하지 않는다.

성공 여부를 확인하지 못하면 동일 ID와 동일 본문으로 재시도한다.

서버는 동일 ID의 중복 저장을 막는다.

## 해석상의 제한

처음 마음 문항보다 축제 소개가 위에 있다.

따라서 처음 마음은 페이지 방문 전의 순수한 사전 점수가 아니다.

최초 점수 선택 시점의 노출 기록을 별도로 보관한다.

처음 점수 수정 시각도 보관한다.

관심 변화와 콘텐츠 노출의 관련성은 살펴볼 수 있지만
이 설문만으로 인과관계를 입증하지 않는다.
